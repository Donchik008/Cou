# Courier - Food Delivery Mobile App

A mobile application for food delivery built with React Native, Expo, and TypeScript.

## Features

The project includes 14 screens:
- Splash Screen
- Onboarding (3 slides)
- Login / Sign Up / Forgot Password / Verification
- Location Access
- Home, Search, Category, Restaurant Details, and Dish Details

## Tech Stack

- React Native / Expo
- TypeScript
- React Native StyleSheet
